## Multimodal Emotion Recognition & Music Recommendation System

A real-time AI-based system that detects user emotions using multiple modalities and recommends personalized music based on the detected emotional state

This project combines Emotion Recognition and Music Recommendation into a single system.
The system supports multiple input modalities:
- Text
- Image
- Live Camera Feed


Based on the detected emotion, the system recommends songs using a K-Nearest Neighbors (KNN) based recommendation engine powered by Spotify audio features.
